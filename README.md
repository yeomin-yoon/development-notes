# 개발 공부 기록

[개발 공부 기록](https://yeomin-yoon.github.io/development-notes/)

개발을 공부하며 정리한 개념과 문제 풀이, 실험 기록입니다.

`site/`는 Quartz로 생성한 공개용 웹페이지입니다. 글은 원본 옵시디언 폴더에서 관리합니다. 개인 PC의 사용자 경로와 컴퓨터 이름은 공개용 복사본에서만 가립니다.

Windows의 변경 감지 프로그램이 원본의 변경을 확인해 공개용 파일을 갱신하고, GitHub Actions가 Pages에 배포합니다. AI 실행이나 원본 공동 저장소에 대한 자동 커밋은 하지 않습니다.

Quartz의 MIT 라이선스는 `site/LICENSE-Quartz.txt`에 포함되어 있습니다.
